# PawHaven — Compassionate Pet Adoption & Rescue Platform

A warm peach-and-cream styled pet adoption, foster matching, and animal shelter management platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Adoptable Pets Directory**: Search and filter rescued dogs, bonded cat pairs, and dwarf rabbits by species, age, and shelter location.
- **Medical & Behavioral Profiles**: View full verification badges (core vaccines, spay/neuter, microchipping), temperament tags, and compatibility with kids/other pets.
- **Favorites & Saved Pets**: Save pet profiles locally to compare and review with household members.
- **Adoption Application Pipeline**: Prospective adopters can submit housing environment details, yard access information, and pet experience.
- **Shelter Operations Console**: Shelter volunteers can publish new rescue listings with stories, adoption fees, and photos.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3040`
